# MECÁNICA TENSORIAL

Repositorio del curso de pregrado **Mecánica Tensorial (Mecánica de Medios Continuos)**: diapositivas, material de repaso, bibliografía, códigos y documentos del curso.

## Estructura

| Carpeta | Contenido |
|---|---|
| [0_BIBLIOGRAFÍA](0_BIBLIOGRAF%C3%8DA/) | Libros y notas de referencia del curso |
| [1_DIAPOSITIVAS](1_DIAPOSITIVAS/) | Diapositivas de las clases (PDF) |
| [2_MATERIAL DE REPASO](2_MATERIAL%20DE%20REPASO/) | Ejercicios y cuestionarios de repaso por tema |
| [3_CODIGOS](3_CODIGOS/) | Códigos de apoyo (Python / MATLAB / Maxima) |
| [4_OTROS DOCUMENTOS](4_OTROS%20DOCUMENTOS/) | Temario, exámenes y demás documentos |

## Contenido del curso

1. Introducción al cálculo tensorial
2. Esfuerzos o tensiones
3. Desplazamientos y pequeñas deformaciones
4. Relación entre esfuerzos y deformaciones
5. Desplazamientos y grandes deformaciones
6. Ecuaciones fundamentales de la mecánica de los medios continuos

El temario completo y las observaciones del curso están en [temario.md](4_OTROS%20DOCUMENTOS/temario.md); las fechas, temas y porcentajes de las evaluaciones, en [examenes.md](4_OTROS%20DOCUMENTOS/examenes.md).
