# 3_CODIGOS

Códigos de apoyo del curso (Python, MATLAB, Maxima): cálculo de esfuerzos y deformaciones principales, círculo de Mohr, cambios de base, gradiente de deformación, etc.

Se recomienda organizar los códigos por tema, por ejemplo:

```
3_CODIGOS/
├── 01_CALCULO_TENSORIAL/
├── 02_ESFUERZOS/
├── 03_PEQUENAS_DEFORMACIONES/
├── 04_LEY_DE_HOOKE/
├── 05_GRANDES_DEFORMACIONES/
└── 06_ECUACIONES_FUNDAMENTALES/
```
